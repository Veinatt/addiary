# Дневник

Личный дневник давления в Telegram. У каждого аккаунта свои записи и свои границы.

## Локально

Два процесса.

```bash
cd backend
cp .env.example .env   # Windows: copy
npm install
npm run dev
```

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

В `frontend/.env` укажи свой числовой Telegram id:

```
VITE_DEV_USER_ID=123456789
```

Пока `AUTH_DEV_BYPASS=true`, браузер без Telegram ходит на API с заголовком `X-User-Id`. В проде обход выключи и впиши `BOT_TOKEN` того бота, из которого открывается мини-приложение. Подпись `initData` проверяется так же, как в NasTask.

Фронт: http://localhost:5173  
API: http://localhost:5001

Часовой пояс дня и времени в записях: Europe/Minsk.

## Что внутри

- Главная: новая запись и список за сегодня. Дату и время можно поменять.
- Статистика: Все / Месяц / День / Период, график, карточки, фильтр, правка и удаление.
- Таблицы: те же периоды и PDF. На бланке название «Дневник» и период.
- Настройки справа в шапке: тёмная или светлая тема, границы верхнего, нижнего и пульса.

Записи лежат в SQLite и привязаны к Telegram id. Чужие строки не отдаются.
